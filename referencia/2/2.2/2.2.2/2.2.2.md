# 2.2.2. Módulo 2 / Integrante 2 (HIDALGO)

> **Módulo 2 – Contenido y Pipeline de Medios.** Atributos dominantes: **performance de procesamiento (throughput)** y **escalabilidad**, con exigencias fuertes de **disponibilidad** en la entrega y de **seguridad** en el acceso al contenido.

### Performance

**ESC-M2-01 — Latencia de inicio de reproducción**
| Parte | Contenido |
|---|---|
| Fuente | Usuario final en red móvil 4G en Lima. |
| Estímulo | Desliza al siguiente video del feed. |
| Artefacto | CDN + reproductor + servicio de manifiestos (M2). |
| Entorno | Operación normal, hora pico (20:00–23:00). |
| Respuesta | El sistema entrega el primer segmento desde la caché de borde; el reproductor usa el segmento precargado del video siguiente. |
| Medida | **Tiempo hasta el primer fotograma ≤ 400 ms en el percentil 95** y ≤ 800 ms en el percentil 99. Tasa de *rebuffering* menor al 1% del tiempo de reproducción. |

**ESC-M2-02 — Throughput de transcodificación**
| Parte | Contenido |
|---|---|
| Fuente | Base de creadores. |
| Estímulo | 3,000 videos subidos por hora, con un pico de 8,000 durante un evento masivo. |
| Artefacto | Cola y flota de trabajadores de transcodificación (M2). |
| Entorno | Pico de carga previsto. |
| Respuesta | La cola absorbe el pico; el autoescalado incorpora trabajadores según la profundidad de la cola; los videos de creadores con alta audiencia usan una cola prioritaria. |
| Medida | **95% de los videos de hasta 60 segundos disponibles en menos de 90 segundos**; ninguno más de 10 minutos. Profundidad de cola de vuelta a la normalidad en menos de 20 minutos tras el pico. |

### Escalabilidad

**ESC-M2-03 — Crecimiento del catálogo**
| Parte | Contenido |
|---|---|
| Fuente | Crecimiento orgánico del producto. |
| Estímulo | El catálogo pasa de 5 a 50 millones de videos en 12 meses. |
| Artefacto | Almacenamiento de objetos, metadatos y CDN (M2). |
| Entorno | Operación normal. |
| Respuesta | El almacenamiento escala horizontalmente; los metadatos se particionan por identificador; el contenido con menos de 10 vistas en 90 días migra automáticamente a una clase de almacenamiento de acceso infrecuente. |
| Medida | Latencia de entrega sin degradación (mismo p95 de ESC-M2-01). **Costo por video almacenado reducido en al menos 40%** gracias al ciclo de vida del almacenamiento. |

### Disponibilidad

**ESC-M2-04 — Caída de una zona de disponibilidad**
| Parte | Contenido |
|---|---|
| Fuente | Proveedor de nube. |
| Estímulo | Una zona de disponibilidad completa queda inoperativa. |
| Artefacto | Servicios de M2 y almacenamiento. |
| Entorno | Falla de infraestructura. |
| Respuesta | El balanceador retira la zona afectada; las réplicas en las zonas restantes absorben el tráfico; los trabajos de transcodificación en curso se reintentan por ser idempotentes. |
| Medida | **Disponibilidad de reproducción ≥ 99.95% mensual.** Recuperación en menos de 3 minutos. 0 videos perdidos. |

**ESC-M2-05 — Falla del pipeline de moderación automática**
| Parte | Contenido |
|---|---|
| Fuente | Proveedor externo de clasificación de contenido. |
| Estímulo | La API de moderación deja de responder. |
| Artefacto | Etapa de moderación del pipeline (M2). |
| Entorno | Falla de una dependencia externa. |
| Respuesta | El sistema adopta la política de **falla segura**: los videos no clasificados quedan en estado `MODERATING` y **no se publican**; se derivan a la cola humana priorizada por alcance esperado del creador; se alerta a Trust & Safety. |
| Medida | **0 videos publicados sin clasificar.** El creador es informado del retraso en menos de 2 minutos. Backlog absorbido en menos de 4 horas tras la recuperación. |

### Seguridad

**ESC-M2-06 — Acceso no autorizado a contenido privado**
| Parte | Contenido |
|---|---|
| Fuente | Atacante externo. |
| Estímulo | Intenta reproducir el video de una cuenta privada usando la URL del objeto en el almacenamiento, obtenida de una sesión previa. |
| Artefacto | Almacenamiento de objetos + CDN + servicio de reproducción (M2). |
| Entorno | Operación normal. |
| Respuesta | El almacenamiento no es públicamente accesible; la reproducción exige una URL firmada con vencimiento de 5 minutos y ligada a la sesión; la verificación de permisos consulta la relación de seguimiento en M4. |
| Medida | 100% de intentos con URL vencida o ajena rechazados. 0 accesos exitosos en pruebas de penetración. |

### Modificabilidad

**ESC-M2-07 — Adopción de un nuevo códec**
| Parte | Contenido |
|---|---|
| Fuente | Equipo de plataforma, buscando reducir costo de egreso. |
| Estímulo | Incorporar AV1 para los dispositivos que lo soportan. |
| Artefacto | Perfil de transcodificación (M2). |
| Entorno | Tiempo de diseño. |
| Respuesta | Se agrega un perfil declarativo en la configuración del pipeline; el manifiesto ofrece la nueva representación y el reproductor negocia según capacidad del dispositivo. |
| Medida | Menos de 5 días-persona. 0 cambios en M3, M4 y M5. Despliegue progresivo con la posibilidad de revertir en menos de 10 minutos. |
